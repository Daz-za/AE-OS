Welcome to AE-OS

This page builds a small, working AE-OS on your computer and shows how each part of it works. It uses Kestrel Foods, the company in the film on ae-os.org, so everything is already filled in. Nothing leaves this computer.

Start here

The guided tour

  1. Set up. Build Kestrel Foods one part at a time: its certificate authority, its people and AI agents, their identities, the books, the rules and the gateway.
  2. Run the close. Watch the agents work through the quarter-end close from the film, and decide as the CFO when the rules stop a write-down.
  3. Try a call. Act as any agent, then look at the evidence an auditor would check.
Change where it is saved

You can stop at any time. To come back later, run aeos ui in the same folder and choose the workspace under Continue where you left off.

Architecture

What to do here

This diagram shows the whole company in the layers of the How it works page on ae-os.org. Select any part to read what it is and open its step under Set up. Faint parts are not set up yet. Calls made on any page, or by your own agents, travel through the parts they touch: each check lights green when it passes, amber when it waits for a person, and red when it refuses.

Live record

Every record the log receives, newest first, including calls made from the command line or your own agents.

      Run the close

      What to do here

      This is the quarter-end close from the film, sent as real calls through the gateway. Play the chapters in order, starting at the top. Each one shows its calls moving through the diagram and lists what happened underneath. Press Show each check on any result to see why it passed or stopped. In the chapter where the CFO decides, you choose for the CFO.

      When you have played every chapter:

      Try a call

      What to do here

      Act as one of the agents. The quickest start is one of the example buttons in the row marked Try: each sends a call at once. Or choose an agent, a tool and its details, then press Send as and the agent's name. The panel beside the form lists each check in the order the gateway ran it. To see the controls refuse a call, choose a tool the agent was not given.

      Build with it

      What to do here

      Every part of the architecture is a module of the open-source toolkit. Use them together, as this workspace does, or take any one into your own platform. Each module below has a short Python example that runs on its own, and the command that does the same from the terminal. Copy any example into your own Python file to try it.

      Edit

      What to do here

      The whole workspace as one file, workspace.json. Each step under Set up has a form for its part; here you can change everything at once, or copy the file to describe your own company. Press Check and save, then run the changed steps again under Set up.
